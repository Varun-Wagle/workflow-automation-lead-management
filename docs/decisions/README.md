# Architecture and Scope Decision Log

Record decisions that materially affect project scope, architecture, reliability, privacy, cost, or maintainability.

Use this format for each decision:

## DEC-XXXX — Short title

- **Status:** Proposed / Accepted / Deferred / Rejected / Superseded
- **Date:** YYYY-MM-DD
- **Context:** What question or problem prompted this decision?
- **Options considered:** What realistic alternatives were assessed?
- **Decision:** What was chosen?
- **Rationale:** Why is this the best fit for the current requirements?
- **Consequences:** What trade-offs, constraints, or follow-up work result?
- **Revisit when:** What new information would justify reviewing the decision?

Do not record secrets, API keys, personal customer information, or credentials in this file.
